# EXPERT Lab - static export

Auto-generated by `python manage.py build_static` from the Django project.
Everything needed to host this site is in this one folder: HTML pages, `static/` (css/js/fonts/images), `media/` (uploads), and `data/*.json` (the full public content, extracted from the database).

## Deploying (no credit card needed)
Any static host works, e.g.:
- **GitHub Pages**: push this folder's contents to the root of a repo (or a `docs/` folder) and enable Pages in the repo settings.
- **Netlify / Vercel / Cloudflare Pages**: drag-and-drop this folder, or connect the repo - no build step needed, publish directory is `.`.

## Updating content
This folder is a build output, not the source of truth. To change content, edit it in the Django admin (kept locally, not deployed), then re-run `python manage.py build_static` and redeploy this folder.
